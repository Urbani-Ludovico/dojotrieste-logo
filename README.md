# A.S.D. DOJO Trieste - Logo

Python script generator for the logo.

## Command line arguments

| Arguments | Type | Default | Description |
| -- | -- | -- | -- |
| `--size` `-s` | positive integer | 1024 | Size of the SVG |
| `--main-color` `-s` | str | "black" | Main logo color |
| `--background` `-b` | str \| None | None | Background of the sakura |
| `--output` `-o` | str | | Output filename |

Available main colors:
- white
- black

Available background:
- white
- `None` (remove background)
